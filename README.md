# Ak-inori Tap

## How do I install these formulae?

`brew install ak-inori/tap/<formula>`

Or `brew tap ak-inori/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ak-inori/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
